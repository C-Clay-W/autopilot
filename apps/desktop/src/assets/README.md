## Autopilot Logo

三份 Autopilot SVG 由项目提供。agent-light.svg 用于当前 Desktop 深色背景下的侧栏 AP 摘要、展开列表和 AP 总台。agent-dark.svg 为深色标识，供浅色背景使用；agent-main-color.svg 为主色标识。三份资源随应用本地打包，AP 浅色版直接显示原色。

侧栏顶部复用 agent-light.svg 并显示 Autopilot 字标。autopilot.png、autopilot.ico、autopilot.icns 从 agent-main-color.svg 按原路径与颜色生成，保留透明背景。PNG 为 1024×1024，供窗口和 Dock 使用；ICO 包含 16/24/32/48/64/128/256px，ICNS 包含 128/256/512/1024px，供 Forge 平台打包使用。
